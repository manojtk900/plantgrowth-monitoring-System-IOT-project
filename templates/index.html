🔍 Why I Built This: Plant Monitor Architecture

Bridging physical edge telemetry with verifiable agronomic insights

Architecture Deep-Dive

Commercial agricultural monitors often hide calculation formulas, fabricate unmeasured parameters (such as synthetic air humidity without an installed sensor), or disconnect firmware from cloud verification. The Plant Monitor was engineered to establish an honest, verifiable, end-to-end data pipeline from physical transducer flight-times to calibrated database records.

Capacitive Soil Moisture

Measures relative soil dielectric permittivity via high-frequency analog oscillation on GPIO 34 (ADC1). Calibrated strictly on the backend via DRY_RAW = 3326 and WET_RAW = 1520.

🌡️

DS18B20 Digital Temperature

Waterproof digital thermal probe communicating over Dallas 1-Wire protocol on GPIO 4 with 4.7kΩ pull-up resistor. Tracks root-zone temperature with automatic fault rejection (-127°C and 85°C).

📏

HC-SR04 Ultrasonic Sonar

Emits 40 kHz ultrasonic pulses on TRIG (GPIO 5) and measures echo round-trip flight time on ECHO (GPIO 18 with 2.5V safe divider) to measure non-contact canopy air distance in centimeters.

🌿

Deterministic Plant Height Calculation Model

Plant Height = Sensor-to-Soil Mount Datum (30.0 cm) - Measured Echo Distance

The 30.0 cm reference value represents the physical mounting baseline of the transducer mount above the empty container soil bed. Height values are deterministically derived from ultrasound echo flight times and are never fabricated.
